ARTWORK

How to send us a file that prints properly.

Two minutes here saves a day at proof stage.

300 DPI AT PRINT SIZE · CMYK OR PANTONE · VECTOR WHERE YOU HAVE IT · NO BACKGROUND
SIDE BY SIDE

The four that come up.

Every pair below changes one thing and one thing only. The left-hand plate is the file we usually get sent; the right-hand one is the same artwork, fixed.

BOTH PLATES ARE SHOWN AT THE SAME SIZE

01 — RESOLUTION300 DPI AT FINAL SIZE

Resolution is only meaningful at the size it prints. A 300 DPI file scaled up to a back print is a 100 DPI file by the time it reaches the screen — so tell us how big it goes, not just what the file says.

02 — COLOUR MODECMYK, OR A PANTONE NUMBER

RGB describes light, CMYK describes ink, and the conversion has to happen somewhere. If you leave it to us we'll get as close as ink goes and show you on the proof — but you'll have more say if you do it before you send.

03 — EDGESVECTOR IF YOU HAVE IT

Vector is geometry, so it redraws itself at any size — a 40mm pocket print and a 2m banner come off the same file. Raster is a fixed grid, and enlarging it just makes the grid bigger.

04 — BACKGROUNDTRANSPARENT — PNG, SVG, AI OR PDF

The press prints what's in the file, and a white background is white ink. On a white garment you'd never know; on anything else it's a rectangle. We can cut one off for you, but it costs a proof round — so it's worth checking before you send.

COLOUR

Why the magenta on your screen isn't the magenta on cotton.

Your screen makes magenta by emitting light. We make it by putting a pigment on a surface and letting it absorb light instead. Those are opposite processes, and the backlit one can reach values that no mixed ink can — the very bright blues, greens and violets especially.

Then the surface argues too. Cotton is dyed, absorbent and woven, so ink sinks in and the weave breaks the colour up slightly. The same ink reads warmer on natural than it does on white, and a light ink on a dark garment sits on an underbase that lifts it a shade.
